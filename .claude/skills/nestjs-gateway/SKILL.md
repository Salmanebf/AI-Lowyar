## DTO with Zod pattern

```typescript
// ask.dto.ts
import { z } from "zod";

export const AskRequestSchema = z.object({
  message: z.string().min(1).max(4000),
  conversationId: z.string().uuid().optional(),
  language: z.enum(["fr", "ar"]).optional(),
});

export type AskRequest = z.infer<typeof AskRequestSchema>;
```

```typescript
// chat.controller.ts
@Post("chat")
@UseGuards(JwtAuthGuard, RateLimitGuard)
async chat(
  @Body(new ZodValidationPipe(AskRequestSchema)) body: AskRequest,
  @CurrentUser() user: User,
  @Res() res: Response,
) {
  res.setHeader("Content-Type", "text/event-stream");
  res.setHeader("Cache-Control", "no-cache");
  res.setHeader("X-Accel-Buffering", "no");
  await this.chatService.streamAnswer(body, user, res);
}
```

## Calling the Python AI service

Through `AiServiceClient` only. Never `fetch()` from feature code directly.

```typescript
@Injectable()
export class AiServiceClient {
  constructor(private readonly config: ConfigService) {}

  async *streamAsk(payload: AskPayload): AsyncIterable<AiEvent> {
    const response = await fetch(`${this.baseUrl}/ask`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(payload),
      // timeout via AbortController
    });
    // parse SSE → yield events
  }
}
```

## Prisma workflow

```bash
# After editing schema.prisma:
pnpm --filter gateway exec prisma migrate dev --name <descriptive-name>
pnpm --filter gateway exec prisma generate
```

Never `prisma migrate reset` on a non-dev database. Never edit migration files after they're committed.

## Telegram

Use the `nestjs-telegraf` package. Telegram handlers go in `telegram.update.ts`. Account linking flow:

1. User sends `/start <token>` to bot.
2. Token previously generated by gateway when user clicks "Link Telegram" in web UI.
3. `bridge.service.ts` validates token, sets `users.telegram_user_id`.

Webhook secret token validation is mandatory.
